# Vintage Romance — Interactive Love Letter

เว็บไซต์จดหมายเซอร์ไพรส์แบบ Static ใช้ HTML, CSS และ JavaScript ไม่มี Backend หรือ Database

## ทดลองใช้งานในเครื่อง
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ `vintage-love-letter`
3. ดับเบิลคลิก `index.html` เพื่อทดลองเปิดในเบราว์เซอร์

## ปรับแต่งจดหมาย
เปิด `script.js` แล้วแก้ไขข้อความในตัวแปร `LETTER`
- `greeting`: คำขึ้นต้น
- `message`: เนื้อหาจดหมาย
- `signoff`: คำลงท้าย
- `sender`: ชื่อผู้ส่ง
- `photo`: ชื่อไฟล์ภาพ เช่น `our-memory.jpg`
- `photoCaption`: คำบรรยายภาพ

### เพิ่มรูปภาพ
นำไฟล์รูปภาพไปวางใน `assets/` แล้วใส่ชื่อไฟล์ใน `photo` เช่น `photo: "our-memory.jpg"`

### เพิ่มเพลง
นำไฟล์ MP3 ที่คุณมีสิทธิ์ใช้งานมาใส่ใน `assets/` โดยตั้งชื่อ `music.mp3`
จากนั้นปุ่ม Play music จะเล่นเพลงเมื่อผู้รับกดปุ่ม (เบราว์เซอร์ส่วนใหญ่ไม่อนุญาตให้เล่นเสียงอัตโนมัติ)

## Deploy ฟรีบน Vercel
1. สร้าง Repository ใหม่บน GitHub เช่น `vintage-love-letter`
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดในโปรเจกต์นี้ขึ้น Repository
3. เข้า https://vercel.com/ แล้ว Sign up / Log in ด้วย GitHub
4. กด **Add New → Project** แล้วเลือก Repository นี้
5. Framework Preset เลือก **Other**
6. ไม่ต้องกำหนด Build Command และ Output Directory ปล่อยค่าเริ่มต้นสำหรับ Static Site
7. กด **Deploy**
8. เมื่อสำเร็จ Vercel จะแสดง URL เช่น `ชื่อโปรเจกต์.vercel.app` ส่งลิงก์นั้นให้ผู้รับได้เลย

## ก่อนแชร์ลิงก์
- ทดสอบบนมือถือจริง
- ตรวจคำสะกดและชื่อผู้รับ/ผู้ส่ง
- ตรวจว่ารูปและเพลงโหลดได้
- อย่าใส่ข้อมูลส่วนตัวหรือข้อความที่ไม่ต้องการให้บุคคลอื่นเห็น เพราะทุกคนที่มีลิงก์สามารถเปิดได้
- ใช้เฉพาะภาพและเพลงที่คุณเป็นเจ้าของหรือได้รับอนุญาตให้ใช้
